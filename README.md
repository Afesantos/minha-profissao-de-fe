# Minha Declaração de Fé — versão com design modernizado

Esta versão atualiza a apresentação visual da página sem substituir a lógica de publicação existente.

## Principais mudanças
- Nova identidade visual em azul profundo, dourado suave, creme e verde discreto.
- Cabeçalho mais limpo com atalhos para o mural e para o formulário.
- Área inicial reorganizada, com maior contraste e chamada para ação.
- Melhorias de leitura na passagem bíblica e no texto de reflexão.
- Formulário, campos, seletor de cores e botão de publicação com estilo mais consistente.
- Cartões do mural com sombras mais suaves, espaçamento e movimento reduzidos.
- Ajustes responsivos para celulares e telas pequenas.
- Estados de foco mais visíveis e respeito à preferência por movimento reduzido.

## Arquivos
- `index.html` — estrutura da página
- `style.css` — estilos e novo tema visual
- `app.js` — lógica existente do mural, mantida
- `50mais_logo.png`, `msgApp.png` — imagens
- `OraçãoHabacuque-Grupo-Águas.mp3` — áudio original

## Publicação
Extraia o ZIP e publique os arquivos na mesma pasta do projeto GitHub Pages, substituindo os arquivos correspondentes. Mantenha os arquivos de imagem e áudio junto de `index.html`.

A configuração do Firebase existente foi preservada. Antes de publicar, confira as regras de segurança do Firestore e teste a publicação, a leitura em tempo real, as reações e o compartilhamento.

Observação: os scripts externos (Firebase, Lucide, html2canvas e confetti) continuam dependendo dos respectivos CDNs.
